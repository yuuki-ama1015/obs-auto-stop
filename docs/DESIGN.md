# Design

## Product

**OBS Auto Stop** は、OBS Studio の録画を自動停止するための外部プラグインです。

- 録画タイマー（最大録画時間）
- 画面静止で録画終了（映像の静止検出）

## Scope

このプロジェクトは OBS Studio 本体を変更しません。

理由:

- OBS 本体と機能を分離できる
- OBS 公式アップデートを利用しやすい
- プラグインを外せば元の OBS に戻せる
- 配布しやすい
- コード管理が簡単
- OBS 本体の巨大なコードベースを変更する必要がない

## 役割分担

OBS 側:

```text
映像取得
録画
エンコード
ファイル保存
```

プラグイン側:

```text
録画時間監視
映像変化監視
終了条件判定
録画停止要求
```

## コンポーネント

| コンポーネント | 責務 |
| --- | --- |
| `plugin-main` | プラグイン登録、初期化、終了、OBS イベント接続、Dock 登録 |
| `RecordingMonitor` | 録画開始/停止検知、経過時間、最大録画時間判定 |
| `MotionDetector` | 縮小フレーム比較、変化量計算、静止状態判定 |
| `StopController` | 自動停止条件の統合と OBS への録画停止要求 |
| `AutoStopDock` | OBS Dock UI、設定変更、状態表示 |

停止要求は `StopController` に集約します。

## 自動停止条件

```text
録画タイマー到達
    OR
（画面静止で録画終了が ON かつ）指定静止時間に到達
        かつ 最低録画時間を超過
    -> OBS 録画停止
```

手動で録画停止した場合は、タイマーと静止カウンターをリセットします。

`録画の自動停止` が OFF のときは、上記の自動停止要求を出しません。

## MotionDetector

- OpenCV は使わない
- `obs_add_raw_video_callback2` で縮小した輝度フレーム（例: 160x90 の Y800）を受け取る
- 前回フレームとの平均絶対差分を % で計算し、感度しきい値と比較する
- 動きがあれば静止カウンターをリセットする
- 静止が設定時間続いたら停止条件を満たす

## Dock UI ラベル

ユーザー向け日本語ラベル（確定済み）:

- 録画の自動停止
- 録画タイマー
- 画面静止で録画終了
- 静止と判断する時間
- 静止判定の感度
- 最低録画時間
- プラグインステータス
- 経過時間
- 静止時間

設定は OBS プロファイル設定の `ObsAutoStop` セクションに保存します。

## 初期段階で入れないもの

- 本格的な映像解析 / OpenCV
- 音声解析
- AI による動画終了判定
- 自動シャットダウン
- インストーラー
- 自動アップデート

これらは後続マイルストーンで追加します。
