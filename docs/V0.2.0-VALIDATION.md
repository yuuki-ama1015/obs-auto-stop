## 最小化修正

`ensureFloatingMinimizeButton()` で既存ウィンドウ種別を `Qt::WindowType_Mask` により取り除いてから `Qt::Window` に変更。Windows では親を保持したまま `WS_EX_TOOLWINDOW` を除き `WS_EX_APPWINDOW` を設定する。

修正後は通常のタイトルバーと最小化ボタンが表示され、独立した `OBS Auto Stop` ウィンドウとして操作ツールにも列挙される。タイトルバーの最小化で従来の画面左下の小さいバーが残らなくなり、ウィンドウのアクティブ化による復帰も確認した。

その後 OBS 最大化時にドック下部が隣接パネルと重なって表示されることを観察したため、`65bddcc` で内容を QScrollArea に入れた。最終 DLL の起動・ドック登録までは確認。画面操作時にツールがユーザー入力の競合を検出したため、スクロール動作・重なり解消・最小化の最終版での再確認は待機中。前候補での確認と区別する。

**タスクバーの項目をクリックして復帰する操作は未確認**。操作ツールが Windows タスクバーを直接選択できないため、ユーザーに最終確認を依頼している。初回検証の収納中最小化案内は PASS。v0.2.0 でフロート→収納→再フロートの往復も確認した。未確認のクリック復帰を完了済みと扱わない。
