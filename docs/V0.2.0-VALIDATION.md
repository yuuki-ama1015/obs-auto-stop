## 最小化修正

`ensureFloatingMinimizeButton()` で既存ウィンドウ種別を `Qt::WindowType_Mask` により取り除いてから `Qt::Window` に変更。Windows では親を保持したまま `WS_EX_TOOLWINDOW` を除き `WS_EX_APPWINDOW` を設定する。

修正後は通常のタイトルバーと最小化ボタンが表示され、独立した `OBS Auto Stop` ウィンドウとして操作ツールにも列挙される。タイトルバーの最小化で従来の画面左下の小さいバーが残らなくなり、ウィンドウのアクティブ化による復帰も確認した。

その後 OBS 最大化時にドック下部が隣接パネルと重なって表示されることを観察したため、`65bddcc` で内容を QScrollArea に入れた。2026-10-21 に最終 DLL で再確認し、高さ約460pxのフロートドックでスクロール値0→332、下部の無音設定・ステータス・最小化ボタンまで表示できた。収納時と OBS 最大化時も隣接パネルへの重なりがないことを確認した。

最終版の「タスクバーに最小化」でウィンドウが最小化されたことを操作ツールで確認し、タスクバーからのクリック復帰はユーザーが操作して「タスクバーから戻せた」と回答した。タスクバーは操作ツールの対象外のため、この復帰確認はユーザー報告に基づく。回答後のツール取得では最小化状態だったため、自動操作による独立したクリック復帰の確認とは区別する。その後アクティブ化で復帰、タイトルバーのダブルクリックで収納し、収納中の最小化ボタンがフロート表示を促す案内を出すことも再確認した。
